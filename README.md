
# FinGuard AI — Stock Market Risk Early Warning System

## About the Project
FinGuard AI is a student project designed to help users understand unusual stock market behaviour by analysing market information and identifying potential risk signals.

## Problem Statement
Retail investors may find it difficult to understand sudden stock price changes and unusual trading volumes. This project aims to make these signals easier to explore.

## Objectives
- Analyse stock market data.
- Identify unusual price or volume movements.
- Display risk-related information in a simple interface.
- Help users learn about market risk.
